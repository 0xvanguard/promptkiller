📋 Quick Setup

1
Install Ollama: curl -fsSL https://ollama.com/install.sh | sh or download from ollama.com
2
Start Ollama: ollama serve (runs on localhost:11434)
3
Pull a model:
ollama pull llama3.1 — General purpose (8B, 70B, 405B)
ollama pull codellama — Code-focused
ollama pull mistral — Fast, lightweight
ollama pull deepseek-r1 — Reasoning model
4
Verify: ollama list — should show your installed models

Models run 100% locally. No internet required after download. Your prompts never leave your machine.

ℹ️ About PromptKiller

🛡️ What is PromptKiller?

PromptKiller is a comprehensive AI red teaming toolkit containing 629 adversarial prompts across 20 attack categories. It's designed for security researchers, AI safety teams, and red teamers to test and harden AI systems against prompt injection, jailbreaking, and manipulation attempts.
